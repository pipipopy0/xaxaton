# Planlit

> Умный планировщик в мессенджере: превращает обычное сообщение в событие календаря и вовремя напоминает о нём.

## Зачем это нужно

Планирование часто ломается в момент, когда человеку неудобно открывать отдельное приложение. Planlit позволяет зафиксировать задачу прямо в диалоге: пользователь пишет, что и когда нужно сделать, а бот разбирает запрос, создаёт событие и возвращается с напоминанием.

Проект объединяет календарь, обработку текстовых запросов и оплату подписки в одном привычном интерфейсе.

## Возможности прототипа

- создавать, изменять и удалять события из сообщений на естественном языке;
- распознавать дату, время, длительность и повторяемость события;
- отправлять напоминания о предстоящих событиях;
- подключать Google Calendar и Apple Calendar;
- учитывать часовой пояс пользователя;
- хранить события, настройки и использование в PostgreSQL;
- поддерживать тарифы и оплату через YooKassa;
- работать на русском и английском языках.

## Сценарий демонстрации

1. Пользователь отправляет боту: «Завтра в 10 утра встреча с командой на час».
2. Бот уточняет параметры, если это необходимо, и создаёт событие.
3. В назначенное время сервис отправляет напоминание.
4. Пользователь может изменить событие текстовым сообщением.
5. При подключённом календаре событие синхронизируется с Google или Apple Calendar.

Для демонстрации платежного сценария можно показать переход на Pro-тариф и обработку webhook YooKassa.

## Архитектура

```text
Пользователь -> MAX Bot API -> bot -> PostgreSQL
							  |       |
							  |       +-- события, пользователи, подписки
							  +-- Duckling, AI API, Google / Apple Calendar

YooKassa -> web (nginx) -> webhook (Flask) -> PostgreSQL
```

## Компоненты

Проект запускается через Docker Compose и состоит из следующих сервисов:

- `bot` — основной бот и фоновые задачи;
- `webhook` — Flask-сервис для webhook YooKassa;
- `web` — nginx для сайта из `SITE/` и проксирования webhook;
- `postgres` — база данных PostgreSQL;
- `duckling` — разбор дат и времени в пользовательских сообщениях.

При старте бот автоматически создаёт необходимые таблицы и базовые тарифные планы.

## Технологии

`Python`, `MAX API`, `PostgreSQL`, `Docker Compose`, `Flask`, `nginx`, `Duckling`, `Google Calendar API`, `CalDAV`, `YooKassa`, AI API для обработки текста.

## Быстрый запуск

- Docker Desktop с Docker Compose;
- доступ к интернету для загрузки образов и Python-зависимостей;
- токены и ключи внешних сервисов.

## Настройка

Создайте в корне проекта файл `.env`. Файл уже исключён из Git и не должен публиковаться.

Минимальный набор переменных:

```dotenv
MAX_BOT_API=...
tg_admin_id=...

host=postgres
port=5432
user=calendator
password=change-me
database=calendator

key_cryptography=...
EXCHANGE_RATE=...
```

Для полной функциональности также настройте переменные внешних сервисов:

```dotenv
POLZA_API=...
POLZA_URL=...
GEMINI_FLASH_3=...
CLIENT_GOOGLE_ID=...
CLIENT_GOOGLE_SECRET=...
TOKEN_URI=...
DEVICE_CODE_URL=...

YOOKASSA_SECRET_KEY=...
YOOKASSA_SHOP_ID=...
TG_BOT_USERNAME=...
```

Если порт сайта `80` занят, задайте другой внешний порт:

```dotenv
WEB_PORT=8080
```

## Запуск

Сборка и запуск всех сервисов:

```bash
docker compose up -d --build
```

## Структура проекта

```text
main.py                    # запуск бота
services/flask_service.py  # Flask webhook
services/database/         # подключение и работа с PostgreSQL
handlers/                  # команды, callback-и и клавиатуры бота
forms/                     # конечные автоматы форм
SITE/                      # статический сайт
media/                     # инструкции и медиафайлы
prompts/                   # шаблоны запросов к AI-сервисам
Dockerfile                 # образ Python-приложения
docker-compose.yml         # все сервисы проекта
nginx.conf                 # сайт и reverse proxy
```
